# broCAD/M logo

The user selected the third displayed monochrome concept: the joined lowercase `bro` above stencil `CAD/M`. The lettering is artwork, not a substituted interface font.

- [Selected stacked master](stacked-master.png), 1254 × 1254 PNG.
- [Horizontal dashboard variant](../../../../src/assets/brocadm-wordmark.png), 2172 × 724 PNG.
- [Matching b favicon](../../../../src/assets/brocadm-favicon.png), 1254 × 1254 PNG.

These are raster assets generated with the built-in image generation tool. Originals are retained unchanged. The header displays the horizontal variant at a measured 24px ink height. CSS reverses its black-on-white artwork to white on the dark header; it does not redraw or replace the letters. The favicon retains black on white so it remains visible on light and dark browser chrome. The wordmark appears only on the dashboard. A failed image request falls back to the product name.

The transparent horizontal attempt was rejected because its edges and counters were damaged. It is not included in the project.

## Prompt set

### Selected stacked master

Design one striking original monochrome identity for broCAD/M, a CAD + CAM platform. A compact custom type logo with `bro` in large lowercase letters above a smaller `CAD/M` line, fitted to the same width. Join the b and r; use a round o and precise stencil cuts below. Pure black on white, flat artwork, open counters, no surrounding box, tagline, gears, 3D, gradients, shadows or texture. The product screenshot supplied interface context only.

### Horizontal dashboard variant

Make a faithful responsive horizontal variant of the approved logo. Preserve the custom rounded lowercase bro letterforms, fused b and r, circular o, and stencil uppercase CAD/M. Move CAD/M to the right on the same baseline, with no spaces and balanced scale. Use solid black on opaque white, smooth contours, open counters and no distressed texture. Frame the wordmark tightly in a wide image for a 24px application header.

### Favicon

Create the small app-icon companion to the approved logo. Use one lowercase b with its tall upright, rounded bowl, squared-to-rounded geometry and large open counter. Finish the right side as a standalone b. Solid black on a white square, centered with modest margins, smooth contours, no border, extra letters, texture or shading. It must remain readable at 16px.
