# Node runtime for maintenance

The repository uses Node 24 LTS for CI and normal maintenance. `.node-version` pins the exact release used by local tooling and both GitHub workflows. The root package and lock-root `engines` declarations must agree, and root and icon-package `devEngines.runtime` declarations must enforce the same range for npm-managed maintenance commands. npm treats `engines` as package compatibility metadata and uses `devEngines.runtime` to reject an unsupported runtime before `npm install`, `npm ci` and `npm run`; direct `node scripts/...` commands rely on the selected `.node-version` runtime and do not consult npm metadata. The application runs on the user's device in a browser and does not require Node to author or import parts.

Use Node 24.22.1 for maintenance. It is the 21 October 2026 Node 24 LTS security release and includes the fixes in that security batch. The compatibility range also retains the previously declared Node 26 line at its patched 26.12.1 floor: `>=24.22.1 <25 || >=26.12.1 <27`. Node 25 and unreviewed future majors are not supported. Update `.node-version`, root `engines`, both `devEngines` declarations, the lock-root `engines` and this guidance together when adopting a later reviewed security release. Do not rely on a floating major selector to pick up a security patch after a workflow has already run.

GitHub jobs use `ubuntu-24.04` to keep runner image migrations separate from application changes. Checkout, setup-node, artifact and Pages actions use their current Node 24 runtime releases. Review action major upgrades and their permission/artifact contracts; do not add write permissions to the PR verification job.

Run a clean `npm ci`, tests, build, release/documentation checks and browser journeys with the selected runtime. Keep the app version independent of the Node version, post schema and engine API version. Changing Node or action runtimes alone does not authorize deployment, a version tag rewrite, package migration or modification of installed post processors.

Primary references: [Node 21 October 2026 security releases](https://nodejs.org/en/blog/vulnerability/october-2026-security-releases), [Node 24.22.1 release](https://nodejs.org/en/blog/release/v24.22.1), [official release checksums](https://nodejs.org/dist/v24.22.1/SHASUMS256.txt), [setup-node](https://github.com/actions/setup-node), [GitHub runner images](https://github.com/actions/runner-images).
