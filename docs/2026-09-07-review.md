## Branch checkpoint

- Explicit folder selection opens the picker. Failed or cancelled switches preserve the current editor; successful switches clear the previous folder's state.
- Execution diagnostics open the tool that resolves them and remain visible alongside geometry diagnostics.
- Initial wire setup uses the document's reviewed position rather than a stale local preview. Shorter instructions and omission of unavailable circle-center choices keep the actions visible.
- Canvas preview includes reviewed initial positioning, authored exits, the following connection, and matching endpoint markers.
- Reversing an open contour invalidates review of manual leads whose connections change.
- Stop edits reject distances outside the active cut length and duplicate enabled placements, with inline explanations. Invalid stored rows remain individually repairable.
- Failed construction picks clear their pending mode, allowing other valid workflow changes to save.
- Text-editor start reordering retains intervening commands, comments, and separators. Moving discontiguous lines returns their actual new selection positions.
- Removed unused posted-transition preview plumbing and its obsolete test, unused geometry work, and redundant formatting wrappers. Split the combined workflow test into independent scenarios.
- Updated README, contributor structure notes, and browser-testing documentation. Dated design records remain historical references.
