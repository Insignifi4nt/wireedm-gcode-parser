## Compatibility-sensitive issue left unimplemented

Arc stop interleaving recomputes length from absolute endpoint angles instead of the accepted source arc length. A tiny half-stop can split source range at `0.4853028997290862` rather than `0.5`, and another valid tiny arc is rejected. Normal-scale transformed probes also expose smaller parameter discrepancies, up to `4.40857e-10`, while retaining contiguous coverage and ordering.

The minimal input is a counterclockwise radius-1 arc centered at `(0, 0)`, start angle `0.1` radians and accepted sweep `1e-16` radians, with endpoints computed from cosine/sine and zero coincidence/endpoint tolerances. Give the initial wire position the arc start, review wire-center compensation, and place an operator-check stop at remaining cut length `sweep / 2`. Structural validation succeeds; both compiler modes produce the distorted range. Changing the start angle to `Math.PI` and sweep to `1e-15` yields `EXECUTION_PLAN_PROGRAM_STOP_INVALID` despite valid input. These extreme cases establish the arithmetic inconsistency; they do not measure its manufacturing significance.

A private source-length value could correct current interleaving without adding event fields. However, existing engine-2 saved revisions recompile with the default compiler and compare canonical plan hashes. A default correction can change historical hashes or output. Preserving engine-1 behavior alone is insufficient. The original audit boundaries prohibit silently changing these contracts, so no compiler formula or engine/version change has been made. A separate explicit compatibility decision is required before implementing this correction.

The concrete local reproduction and candidate design are retained in `tmp/audit-2026-10-11/adversarial-geometry/candidate-fixes.md`. This is a known remaining issue, not an assertion that the application is defect-free.

## Other remaining limits and deliberate nonchanges

- Partial, missing or failed storage inventories cannot prove that a proposed parent file has no unseen descendants. The new preflight uses known paths and direct ancestor reads. A global rejection of every new file in a large workbench would disrupt valid workflows and was not introduced. No partial inventory authorizes deleting unknown files.
- External folder writers can bypass browser Web Locks. Exact checks preserve unknown data at the inspected boundaries; File System Access supplies no cross-process compare-and-swap transaction. Fault tests use real cache adapters and fake folder handles, rather than physical filesystem crash injection.
- Invalid touching/intersecting geometry with manually overwritten contour roles has 26 direct material-classifier result differences in the independent corpus. All 32 invalid documents still reject execution independently. Recomputing all intersection eligibility on every public classifier call cost about 117 ms at 500 nested contours, including the editor's between-contours panel consumer. That experiment and a speculative bespoke circular fast path were excluded. The conditional source check covers the proved valid/reviewed ancestry cases; exact warning parity for invalid manually overwritten geometry remains a separate opportunity.
- Malformed inactive union fields and other stale finite caches can still expose validation shape gaps without a demonstrated execution drift or crash. Broad frozen-format tightening was excluded; the new checks target proved failures.
- Ordinary cache reads still decompress before downstream size checks. Read-only recovery is bounded. Changing ordinary limits needs a compatibility decision for existing large readable projects.
- Chromium workflows, controlled worker substitutes and finite corpora do not cover every browser, native worker event failure, physical controller or numerical configuration. The existing chunk/externalization build warnings remain. No standalone lint command exists; strict TypeScript, tests, documentation/contract checks and whitespace checks are used.
