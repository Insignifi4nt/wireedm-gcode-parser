- Containment uses the complete analytic bounds, including signed-arc extrema. Crossing clips only the query rectangle, rejects disjoint bounds, then checks an actual curve point or analytic boundary intersections. It does not accept AABB overlap alone or treat a circle's interior/center as an edge. Construction entities retain their source identities. Box results contain explicit targets only; points, endpoints and topology are never merged or inferred.
- Intersection tolerance comes from the source segment's bounds through the existing CAD roundoff policy. Distant query corners cannot enlarge it. Existing cases cover tiny/translated curves, major/minor sweeps in both directions, tangency, collinear boundary contact, empty interiors, stable source-order-independent results and invalid/nonfinite bounds/scales.
- Auto/Points/Edges filter candidates before ranking/querying. Public filter commands validate the strict enum, active unsuppressed sketch, available sketch renderer and existing workflow/busy guards. Changing the screen filter does not alter accepted geometry or selection, and exact-ID selection remains independent. The observed filter participates in capture identity, so a filter change during capture rejects the result.

## Box ownership and graph-layer follow-up

The second bounded pass covered `useCadSketchBoxSelection.ts`, `CadSketchGraphLayer.tsx` and their focused integration assertions. Canvas/Workbench production source and the unfinished overlap chooser remained excluded. Root supplied the existing 39-case Layer/Canvas green log; this reviewer did not repeat that run or add fuzz/tests.

Three concrete integration gaps were reported to root:

1. **Pointer selection and keyboard focus disagreed.** When the prepared winner was point `mixed` but SVG point `b` received the event, selection chose `mixed` while focus stayed on `b`; a subsequent keyboard action could target `b`. Root repaired both pointer paths to focus the exact rendered kind/ID winner, preserving the no-implicit-secondary-drag guard. The existing ranking case failed first, then the Layer suite passed 18/18 (`tmp/sketch-spatial-focus-red.log`, `tmp/sketch-spatial-focus-green.log`). The repair was source-rechecked.
2. **A competing pointer did not cancel a box.** The hook rejected another `begin` while retaining its previous owner, and root confirmed the caller ignored that second start. Releasing the first pointer then published the old box despite the plan's second-pointer cancellation rule. Root now routes the competing start through the hook, which cancels the owner before returning. The reproducer failed first, then all seven spatial cases passed (`tmp/sketch-spatial-competing-red.log`, `tmp/sketch-spatial-box-green.log`). The hook repair was source-rechecked; Canvas production source remains excluded from this pass.
3. **Filtered empty clicks were swallowed.** With Points filtering and no eligible point beneath an SVG edge, pointerdown correctly reached the canvas, but Layer's unconditional click containment prevented its normal empty-click behavior. Root reproduced the missing parent click (`tmp/sketch-spatial-filter-empty-red.log`) and changed containment to follow the eligible prepared hit, while keeping exact keyboard activation filtered. The repair was source-rechecked and is covered by the later 132-case UI group and 44-case follow-through results below.

Other reviewed paths keep the captured base selection, compute Shift symmetric difference once per query and validate the final complete set before the single release publication. A rejected oversized set preserves the prior selection. Source/preparation, version, frame, filter, enabled/locked state, blur and initiating-pointer cancellation clear ownership; cancel publishes the late-click suppression callback. GraphLayer uses the prepared hit rather than paint order, excludes filtered kinds from keyboard actions/tab order and prevents multi-selection from moving an implicit primary point. This pass does not establish real-browser gesture or capture behavior.
