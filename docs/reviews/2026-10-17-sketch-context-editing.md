# Sketch context editing

## Problem and contract

The final workflow audit identified one ordinary access gap: graph points and curves had a context menu, but their normal Dimension and Move editors were reachable only through the dock. The existing sketch [interaction reference](2026-10-16-sketch-workflow-reference.md) calls for pointer, keyboard and context routes to reuse the same application operations.

Keep this repair inside the current menu and editor ownership. Right-click or Shift+F10 captures an actual point/curve target. When that target belongs to the selected set, Move retains that set; an outside target gets its own scope. Dimension uses the eligible captured operands. Generated/linked geometry retains its actual owner restrictions. Menus must reject stale source, view or pending-owner changes, close their own pending state before opening the existing editor, and restore the focused atom on Escape. No new operation, persisted record, solver equation or form is needed.
