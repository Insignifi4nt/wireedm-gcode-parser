## Contract and implementation

Add a small pure measurement reader for one accepted graph and parameter map. It reads a point's local coordinates, one line/arc/circle's analytic dimensions, or the signed second-minus-first separation and distance between two points. Line length uses endpoint distance; arc length and directed sweep use the existing analytic segment constructor, including major clockwise/counterclockwise arcs. Circle radius, diameter and circumference follow its exact scalar. These are calculated values, never saved drivers, solver edits or fake zero values. Reuse the reader for existing WebMCP entity-inspection rows; no new tool, argument or write operation.

The human inspector shows compact read-only values for a singleton point/edge or point pair. It measures the accepted/current display geometry, never unsolved form drivers: while a relation edit or preview is pending, hide the passive readout and keep existing editing/preview controls. Cancel brings the accepted readout back. No extra panel or editable coordinate boxes, stored reference-dimension schema, solver work or whole-graph compile is necessary.

Keep existing short relation lists unchanged. For selections with more than four incident relations, use the existing native details/summary disclosure pattern with its count; the selected active relation must remain discoverable/visible when an annotation or command opens it. Do not change which constraints are incident, storage, ownership, removal or highlight callbacks. Opening/closing the disclosure is not a CAD edit.
