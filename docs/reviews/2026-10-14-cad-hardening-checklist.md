Make the existing standalone CAD reliable, responsive and clear for the morning review. Prioritize correctness, direct interaction, clean geometry/lighting and compact UI. No new feature kinds before an independent final review finds no actionable issue in existing scope.

Evaluate selectable sketch regions, explicit nesting/material semantics, live feature previews and optional on-part manipulators. Treat these as product reasoning examples, not permission to abandon hardening for a feature checklist. Preserve exact numeric/expression inputs and deterministic API operations alongside any human handles.

Preserve the user's unsaved gear, installed plugin/post snapshots, saved CAM revisions, browser-cache and folder behavior. Changes stay local for review; shipping requires a reviewed PR. Do not claim universal CAD functionality or physical manufacturing certification from tests.

Use small behavior-driven fixes. Establish a failing regression or measured baseline before changing production code. Expected geometry comes from worked fixtures, independent analytic properties or native material evidence, not a copy of implementation math. No text-presence or implementation-mirroring tests without a meaningful user invariant.
