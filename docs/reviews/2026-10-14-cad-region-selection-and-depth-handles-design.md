# Closed-region selection and optional extrusion depth handles

These are outstanding interactions in existing features, not implemented capabilities or a claim of overall CAD completion.

## Verified reference behavior

Onshape's Solid Extrude accepts faces and sketch regions. Its graphics selection can replace the initially selected closed sketch areas; depth can be entered numerically or changed with a manipulator arrow before the feature is accepted. The FeatureScript tutorial makes the region distinction concrete: its sketch creates five regions, then a query selects only the central region for extrusion. Those resolved areas are different from authoring entities. [Extrude](https://cad.onshape.com/help/Content/PartStudio/extrude.htm), [Add sketch geometry](https://cad.onshape.com/FsDoc/tutorials/add-sketch-geometry.html). Official figures: [Extrude dialog](https://cad.onshape.com/help/Content/Resources/Images/feature-tools/extrude-defaults.png), [queried sketch region](https://cad.onshape.com/FsDoc/tutorials/images/debug-sketch-region.png).

SketchUp's Push/Pull selects a face, displays the changing depth while the pointer moves, and completes it with another click. The Measurements box supports an exact quantity and unit, and Escape abandons the operation. That supports combining a physical gesture with precise numeric editing; it does not establish parametric identity or history semantics for this app. [Pushing and Pulling Shapes into 3D](https://help.sketchup.com/en/sketchup/pushing-and-pulling-shapes-3d), official [Push/Pull figure](https://images.ctfassets.net/yd21npj2ir9g/991e08a62a2f8a303be1f8/f8bfd6a0354167419f1f57f13cfc6d32/fg008_2.png).

## Current application boundary

`cadDocument.ts` and the strict `cadSchema.ts` save `sketchId` for Extrude, Revolve and through-all Pocket, without a region selector. `cadSketchGeometry.ts:resolveCadSketchRegions` validates complete contours and constructs a containment forest. Even-depth contours add material; immediate odd-depth children are holes. Construction contours are excluded. Contact, crossing and self-intersection remain errors. Native `cadKernelModel.ts:fromSketch` and Pocket resolution consume all inferred material regions.

This accurately handles whole sketches with nested holes/islands and disconnected profiles. Picking a source contour currently picks its whole sketch. A subset control must therefore start at the shared document/API boundary; a UI that merely filters the profiles would silently reinterpret holes and is incorrect. The related source audit is `2026-10-14-cad-pad-pocket-region-source-audit.md`; current scalar/navigation behavior is recorded in `2026-10-14-cad-depth-navigation-and-handle-audit.md`.

## Smallest sound region contract

Keep an absent selector exactly equivalent to today's whole-sketch parity behavior. An explicit nonempty selector identifies bounded cells in the complete validated contour forest, including cells currently treated as voids. For a contour, its cell is its interior minus its immediate child interiors. Selecting the annulus around a bore, the bore disk, or both must respectively produce an annulus, a disk, or their full union.

A proposed saved cell reference uses the boundary profile ID plus a canonical list of immediate void profile IDs and containing profile IDs. This topology signature survives profile renaming, reordering and ordinary scalar changes. It prevents a deleted hole, changed nesting or newly inserted child from silently replacing the chosen area. Reject a missing, suppressed, construction, nonpreceding or changed cell with an actionable feature diagnostic and the preceding valid model. Do not substitute the first surviving cell or another sketch. Preserve original source text and pinned plugin definitions; a selection does not extract or regenerate a sketch.

Resolve the complete forest once, validate saved references, then form the selected union. At each contour, compare selection of its cell with selection of its parent cell; retain the boundary only when the two differ. The unbounded exterior is always unselected. Assemble retained boundaries into outer cycles and holes before creating native sketch faces. This cancels a shared contour between adjacent selected cells, avoiding duplicate interior walls or contradictory outer/hole use. Three concentric cells selected together leave only the outer boundary.

The first bounded implementation can support the already accepted nested/disjoint closed contours. Arbitrary overlapping or edge-adjacent sketches require an analytic planar arrangement: intersection splitting, oriented edge incidence and stable fragment identities. Current line/arc paths have profile IDs but no stable individual edge IDs. Profile IDs alone cannot identify all faces of such an arrangement, and selecting a subset must not weaken current contact/intersection validation. That is a separate foundation, not an honest claim of full Onshape parity.

Use one shared resolver for inspection/picking, preview, measurements and native input. Physical point picking is transient; save the resulting cell reference, not a click point, array index, native topology key or build ID. Agents need paged cell inspection and the same guarded edit contract. The human sees shaded selectable areas and a compact selected-area control; the API can retain the full identity/signature information without front-facing bloat. Existing feature kinds remain sufficient.

## Optional physical depth interaction

Add a device-local CAD interaction preference, independent of saved geometry, for handles on the active distance Extrude editor. Through-all Pocket has a direction rather than a depth and must not display a fictitious distance handle. `resolveCadSketchPlacement` supplies the true frame and normal: XY +Z, XZ −Y, YZ +X, or the resolved datum normal. Place the handle on the actual extrusion end along that normal. Symmetric distance is total thickness: moving one cap changes the distance by twice its signed displacement. Preserve existing signed depth and operation choices.

Reuse the editor's scalar intent rather than writing a number directly into the feature. Literal edits change its scalar; a single named alias changes the parameter while preserving its exact expression; a compound relation remains locked until explicit fx editing/unlinking. No-op gestures retain exact accepted literal precision and representation. The smallest shared seam is the existing numeric value operation extracted for both `ScalarValueField` and the handle.

Pin the gesture to editor owner, accepted version, source/frame and binding. Compute displacement from a frozen world-normal line and pointer ray; an end-on/ill-conditioned view requires rotation or numeric entry instead of an invented pixel-to-depth scale. Use local render coordinates only for display precision. Pointer moves update the private feature-plus-parameter candidate; they do not write storage, accepted kernel state or history. Pointer release settles that draft; Apply makes the existing single atomic Undo step. Gesture cancellation restores its starting provisional batch, preserving earlier typed edits; full Cancel restores the accepted document. Escape, lost capture, blur, owner/source/version changes and preference disabling cancel ownership. Pending/last-valid preview labels remain truthful while native work catches up.

## Meaningful acceptance work before UI exposure

Region regressions should independently verify a rectangle/bore/island/disconnected contour fixture: each cell alone, adjacent cells together, all cells, signed/symmetric extrusion and relevant Cut quantities. Preserve legacy whole-sketch volumes and exact originals. Exercise rename/reorder, stable scalar edits, deleted/construction/suppressed sources, changed void/nesting signatures and stale edits. Shared boundary cancellation must be proved by complete native volume/topology, not badge counts; touching/overlapping inputs remain rejected until a real arrangement exists.

Handle regressions should work independent XY/XZ/YZ and rotated-datum world endpoints; signed and symmetric depth; shared aliases versus locked compound formulas; exact no-op precision; provisional changes followed by pointer cancellation/full Cancel; stale owner/source; and one accepted correlated Undo/Redo. Actual physical pointer and preview evidence is needed after those shared operations pass. This research adds no tests or production code during the frozen CI gate.
