Base: stable `3e3fce9` / app 0.0.696. Implementation is isolated on `feature/parametric-cad-workbench`; the existing optimization checkout is untouched. Candidate app version is 0.0.697.

## Delivered behavior

The desktop CAD workspace shares one immutable, versioned model between the interface and WebMCP tools. Named dimensions and bounded arithmetic drive closed rectangle, circle, polygon and slot profiles; ordered features build exact OpenCascade solids with pads, revolves, Boolean operations, whole-body fillets/chamfers, transforms, mirrors and linear patterns. The feature tree, property editor, history and demand-rendered viewport use these application operations.

CAD saves use the existing cache/folder storage lock and file journal with exact stored fingerprints. JSON preserves history; STEP exports BRep; STL exports tessellation; DXF preserves analytic sketch curves. Sketch and final-solid section handoff validate clean millimetre geometry and create detached CAM projects through ordinary portable-UPID import. They do not generate controller output or mutate installed packages or saved CAM revisions.

The agent surface adds schema discovery, bounded complete-document reads, atomic edits, analytic sketch measurements, exact body measurements, section inspection, shared saves/exports/handoffs, viewport commands and real PNG captures. Public instructions work from the hosted app without a checkout or terminal.

## Compatibility and limits

The app version advances once. New CAD schemas are independent of unchanged UPID/post/package/engine contracts. There is no migration, automatic cleanup or silent rewrite. Backup retains all CAD files, including unrecognized future or malformed documents. Source CAD save and CAM creation are separate commits; failures report that distinction.

Fresh nearly tangent calculations include the numerical intersection correction, so newly calculated geometry can differ at roundoff boundaries. Existing saved geometry, packages and generated bytes are unchanged. Sections reject ellipses, splines, open/branched contours and tangent or ambiguous results rather than silently flattening them.

General geometric constraints, assemblies, freeform surface authoring, arbitrary face sketching and reconstruction of imported STEP feature history remain outside this checkpoint. Dimensions use millimetres and angles use degrees. Initial exact-kernel loading costs a lazy WASM download; builds and meshes have explicit resource limits. The viewport and feature history remain responsive while worker computations run.

## Ordered lofts and compact agent discovery

Loft connects 2–16 explicitly ordered sketches on parallel principal planes. Every active section must resolve to one material boundary without holes; construction contours do not participate. Offsets must increase or decrease strictly, beyond native precision and a scale-aware floating-point margin. The editor preserves the supplied order and offers focused move, replace, add and remove controls in a bounded list. Smooth uses fitted native surfaces; Ruled connects consecutive sections directly. New creates a body; Join and Cut replace their explicit target. Sketches remain editable in history.

The implementation uses OpenCascade's through-sections builder with compatibility checking and immutable input wires. It verifies a single closed, native-valid, positive-volume solid and rejects fitted surfaces extending beyond the end-section planes before applying a Boolean. Temporary drawings, planes, wires, builders and failed results are released; failed features retain the preceding target. These checks do not constitute a mathematical proof against every possible interior self-intersection. Unsupported analytic CAM sections remain explicit failures; STEP retains the native fitted BRep.

Reference decisions: [Onshape's ordered loft profiles](https://cad.onshape.com/help/Content/PartStudio/loft.htm), [Fusion's section and operation controls](https://help.autodesk.com/cloudhelp/ENU/Fusion-Model/files/GUID-EC6CECCD-55C1-4B08-95E4-5B1EEDE78D07.htm), and [OpenCascade through-sections options](https://occt3d.com/dev/doc/refman/html/class_b_rep_offset_a_p_i___thru_sections.html). This checkpoint does not add guide rails, mixed sketch planes or tangent end controls.

Dependency discovery now distinguishes sketch inputs from consumed bodies in one exhaustive feature switch. Independent review fixed the new Loft's expanded-instance preflight count to include its generated operand plus its target. Existing Pad/Revolve preflight behavior is preserved. Active invalid sections fail atomically; suppressed lofts retain typed preceding references without preventing upstream geometry edits. The editor also preserves consumed inputs when editing earlier history. Unavailable references in suppressed features display their actual stored name rather than visually substituting another body.

Agent registration now advertises compact common feature envelopes for edit and document import. Per-kind discovery supplies complete definitions; execution still uses the original strict schemas before the shared controller. Malformed fields, accessors, unexpected properties, cancellation, outer bounds and document limits retain their checks. Combined edit/import argument metadata decreased from 73,061 to 5,801 UTF-8 bytes (about 92%) for this schema set. The reduction concerns registration metadata, not saved documents or native model size.

## Direct analytic path construction

Path now authors a connected contour from lines and three-point circular arcs. The interaction selects an arc's endpoint before its through point, following the documented [Fusion](https://help.autodesk.com/cloudhelp/ENU/Fusion-Sketch/files/SKT-CREATE-ARCS.htm) and [Onshape](https://cad.onshape.com/help/Content/Sketch/3_point_arc.htm) order. Signed traversal preserves both short and long arcs. Line/Arc, Undo last and explicit Close controls appear only during Path drawing. The close caption identifies when a final straight edge will be added. Fixed six-pixel snapping makes an off-grid start reachable without saving implicitly; keyboard motion avoids the pointer's snap radius so it remains usable when zoomed out.

The constructor translates and scales coordinates before its circumcenter solve, bounds determinant uncertainty, and checks reconstructed points using the existing saved-path closure tolerance. Coincident, uncertain, unencodable and out-of-range arcs fail without substituting lines. Closure validates the complete analytic contour before the ordinary whole-sketch edit checks nesting and contact. The immutable local drawing retains logical endpoints and survives both construction and document-validation failures. Accepted closure makes one history edit; incomplete picks are never persisted. Hover computes only the next segment, while saved profiles and committed draft geometry are memoized.

The read-only `cad_construct_path` tool shares that constructor and returns geometry, analytic area, perimeter and bounds. It accepts numeric plane-local millimetre points, up to 128 steps, and does not bind parameter expressions or mutate the draft. Insertion remains a normal versioned edit. Saved paths retain their existing 2,048-edge limit and schema. No storage migration, installed-post or CAM revision change is involved.

Independent native review verifies exact D profiles, clockwise concave arcs, signed major arcs and angular-seam cases through BRep extrusion, analytic sections and DXF reimport.
