# CAD rebuild failures and notifications

The user's unsaved module 3, 50-tooth v2 gear with a 12 mm bore and symmetric 10 mm extrusion exceeded the 10,000 face/edge body budget. Its directly edited module/tooth inputs override the document's named parameters. The root outline had 2,600 edges; extrusion expands the boundary into approximately four topology elements per edge. The second diagnostic explained the stopped rebuild and preceding-feature preview rather than a separate geometry failure.

CAD now reports operation and current completed-build failures through the existing app toast/history operation. A build's cause includes its stopped-preview context in one message. Stale and in-progress results are ignored. Repeated identical failures are suppressed until the issue clears, while new causes and failures in another document are reported. Feature tree warning markers and tooltips remain. The old floating diagnostic list and error banner are removed. Toast text wraps so users can read the cause. Dismissing a toast retains its entry in the existing session notification history; this change does not add cross-reload history persistence.

Geometry investigation replaces dyadic root subdivision with certified greedy chord spacing. Every chord still satisfies the analytic second-derivative error bound at the requested tolerance. Safety caps remain unchanged, and geometry is never automatically coarsened to fit a body. Larger prism profiles receive an early actionable topology diagnostic.

The exact current draft was preserved before edits, and the live browser verified a toast, dismissal and retained notification. Focused UI/notification checks pass 44 tests; app/workbench controller checks pass 37 tests. The final CAD run passes 90 files / 1,098 tests, including 26 generated-gear numerical tests and 3 native cases. Production TypeScript/build, documentation parity and pinned corresponding-source distribution pass. Existing bundle/externalization warnings remain.

The module 3 / 50-tooth outline decreases from 2,600 to 2,400 boundary edges. Exact native inventory is 9,610 faces and edges, including the bore's two semicircle walls. Tests independently verify volume, bore circles, section closure, accuracy bounds and unchanged input values. A 60-tooth case at the same tolerance fails before native construction with an actionable diagnostic and unchanged precision.
